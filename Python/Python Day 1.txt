1. Interpreter and Compiler in Python:

Interpreter:

- An interpreter executes Python code statement by statement.
- It helps to run Python programs.
- Example: Python Interpreter.

Compiler:

- A compiler translates source code into another form before execution.
- Python compiles source code into bytecode before execution.
- Examples: C and C++ compilers.

2. Object-Oriented Programming Approach in Python

Definition:

Object-Oriented Programming (OOP) is a programming approach based on classes and objects.
 Python supports OOP.

Main Concepts of OOP:

1. Class: A blueprint for creating objects.
2. Object: An instance of a class.
3. Inheritance: Acquiring properties and methods from another class.
4. Polymorphism: One interface with different behaviours.
5. Encapsulation: Combining data and methods into one unit.
6. Abstraction: Hiding implementation details.
